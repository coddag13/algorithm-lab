# Algorithm Lab

Algorithm Lab is an educational full-stack web application for visualizing,
analyzing, and comparing algorithms.

The first module is a Sorting Algorithm Visualizer & Analyzer built with an
Angular frontend and an ASP.NET Core Web API backend.

## Repository structure

- `frontend/` — Angular application
- `backend/` — ASP.NET Core Web API
- `docs/` — project documentation and technical decisions
